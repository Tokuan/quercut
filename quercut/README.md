# Quercut

Гильотинный раскрой листовых материалов на Python.

## Возможности

- 4 стратегии раскроя (Simple Rip, Simple Cross, Optimal, Advanced)
- Поддержка подрезки краёв (trim)
- Учёт толщины реза (kerf)
- Поворот деталей (grain direction)
- Визуализация в SVG
- Чёрно-белый режим для печати
